# Neuma

**Chorał gregoriański i śpiew liturgiczny** – neumy na czterolinii, psalmodia, tony czytań i Ewangelii (z wyjaśnieniem, kiedy który), odtwarzanie z podświetlaniem nut i wydruk.

Cała aplikacja to jeden plik `index.html` – działa w przeglądarce i offline (można ją zainstalować na telefonie i komputerze).

## Wdrożenie
Netlify: **Add new site → Import an existing project → GitHub → Neuma**. Bez polecenia budowania, katalog publikacji: `.` (ustawione w `netlify.toml`).
Alternatywnie GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

Neuma powstała jako część AugustApki (pomoc w nauce dla rocznika św. Augustyna) i jest z niej budowana – zmiany wprowadza się w źródłach AugustApki.
